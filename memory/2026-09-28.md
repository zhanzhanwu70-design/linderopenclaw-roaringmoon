### A. MeshHeal（arXiv:2609.29015v1, 2026-09-24）
- Gray failure 定義：agent 仍 protocol-compliant 但 task-solving quality 退化
- Two-Timescale Closed Loop：
  - Fast: single-reviewer → committee deliberation → correction before use
  - Slow: peer-relative detector → persistent assess → exclusion → recovery probe → reintegration
- 量化：**0.839 accuracy @ 51k tokens/task** vs Symphony 0.807 @ 115k tokens
  - +3.2pp accuracy, −55% token
- 方法論突破：Model-Backed MAS Evaluation 強制 execution model ↔ declared ability 綁定，避免 hidden routing error

### B. Loop-Back Authority（arXiv:2609.14767, 2026-09-13）
- 單變因配對實驗：5 agent 固定所有，只改 Manager 是否擁有 reject+revise authority
- Flat 顯著勝出：Utility d=0.42 (p=0.009)、Writing Clarity d=0.34 (p=0.030)
- Hierarchical hedge +53%、每 revision loop −0.14 Clarity、supervisory tier +51.5% token 無品質增益
- 金句：**"A supervisor pays for itself when it can verify and becomes a liability when it can opine."**

### 雙軸耦合推論

- Self-healing 節省 55% token
