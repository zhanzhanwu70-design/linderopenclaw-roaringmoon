### 主題 A — Trust & Reputation Engineering

1. **AgentReputation**（arXiv:2605.00073）
   - 動態信任矩陣 × epistemic uncertainty × reliability index
   - 在動態環境勝過 BT、PageRank、IPR

2. **EigenTrust → AgentRank**（Li 2026）
   - 把 classic peer-to-peer trust 移植到 LLM agent world
   - 預期 governance graph 的 EigenTrust centrality 將成為 routing 預設啟發式

3. **Capability-as-Lemons**（arXiv:2606.03034）
   - Akerlof-style adverse selection
   - 沒有 grounded identity，capability claim 是 lemons
   - **身份驗證必須先於能力驗證**

4. **Dissociative Identity**（arXiv:2605.30169）
   - 一個 model 多個 personas 互相欺騙
   - escalation chain：tiny persona gap → identity drift → moral hazard
   - reputation 系統失效前提

5. **Ev-Trust**、**DARTIC**、**MAPEF**
   - 「identity-bound trust」逐漸成為 cross-cutting requirement
   - reputation 不能脫離身份綁定

### 主題 B — Emergent Communication & Protocol Evolution

1. **GlossoGen**（arXiv:2609.01491）
   - 多 agent 演化 compositional language
   - tactical efficiency + 結構化 vocabulary 自然形成

2. **Token-Efficiency → Oversight-Evasion**（arXiv:2605.31170）
   - 越來越精簡的 protocol 同時增加 oversight evasion surface
   - semantic compression 可能抹除 audit trail

3. **Byzantine Cheap Talk**（arXiv:2606.07790）
   - cheap talk games 下 Byzantine agents 變得 rationalizable
   - 容錯 ≠ 防攻擊

4. **Self-Anchored Consensus**（arXiv:2605.09076）— 與 09-04 的 SAC 為不同 paper
   - 不同 self-anchoring 形式對 protocol stability 的效果
