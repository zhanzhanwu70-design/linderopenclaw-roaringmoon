### 三個跨主題核心發現

1. **Mechanism design 把 LLM 從 noisy actor 變 verifiable participant**
   - Albayaydh & Zhao (arXiv:2608.14613) 把 VCG / alternating-offers 編碼進 A2A message schema + runtime verifier
   - 結構化 protocol 把 close rate 拉到 100%、壓低 outcome variance
   - 純 prompt 設定下 buyer-seller bargain close rate 可低於 27%（arXiv:2402.15813）

2. **Reputation + explicit coalition reasoning 是 coalition 穩定的催化劑**
   - Guo et al. (arXiv:2604.14386, HKU) 首個把 LLM coalition 形式化進 hedonic game
   - CoalT prompting 達 73.2% Nash stability
   - LLM 偏好是 ε-rational，對應 QRE noise parameter
   - RepuNet (arXiv:2505.05029) 用 reputation + network rewiring 阻止 cooperation collapse
     - 高 rep agent 自聚類、defector 自隔離

3. **Communication 是 cost，不是 free good**
   - DALA (arXiv:2511.13193) 把 bandwidth 當稀缺資源拍賣
   - agent 學會 concise message，token 成本降 30-70%
   - 與 09-10 SwarmWorld stigmergy 結論互補
   - blackboard (arXiv:2510.01285) 是結構化 stigmergy
