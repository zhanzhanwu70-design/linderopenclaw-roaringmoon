### 本週主題
**Human-AI Collective Decision-Making × Emergent Communication & Coordination**

### 主題 A — Human-AI Collective Decision-Making

1. **CAMH（Collaborative Agent for Multi-Human）**（arXiv:2505.13788）
   - 把 multi-agent LLM 概念擴展到「一個 agent 對多個 human」關係
   - 對 OpenClaw：subagent 與人類互動需要 stateful relationship，不是 stateless Q&A

2. **GUI-based Multi-Agent Framework**（arXiv:2509.05506）
   - 透過 GUI 操作多個 LLM 共同完成任務
   - 可作為未來 team dashboard 雛型

3. **MAD4HG（Multi-Agent Debate for Heterogeneous Goals）**（arXiv:2508.02903）
   - heterogeneous goals MAS 設計
   - 對 OpenClaw：未來跟不同角色的協作範本

4. **HyDiscGAN**（arXiv:2509.01364）
   - Hybrid discrete + continuous control
   - 部分任務必須 hybrid，純離散 policy 不足

5. **MAS-ZCO**（arXiv:2510.05370）
   - Zero-shot coordination
   - 跟未知 agent 也能協作的能力是 future-proof 設計

### 主題 B — Emergent Communication & Coordination

1. **AutoQAG**（arXiv:2609.14978）
   - Auto-question answer generation
   - 提升 multi-agent system 的溝通效率
   - 對 OpenClaw：自動生問答可作為 memory retrieval 替代

2. **Emergent Communication Through Phase Transitions**（arXiv:2609.10944）
   - Communications protocols 經過相變（phase transitions）形成
   - protocol design 不是 artificial，是 emergent
   - 對 OpenClaw：要給 protocol 演化空間（constraint-based, not rule-based）

3. **Multi-Agent Communication Graph**（arXiv:2609.02936）
   - 通訊 graph 結構本身是研究標的
   - 動態 graph = self-organizing 的延伸

4. **Stochastic Coordination**（arXiv:2609.15986）
   - 隨機協調在某些 settings 比 deterministic 好
   - 對 OpenClaw：randomized routing / load balancing 有理論基礎
