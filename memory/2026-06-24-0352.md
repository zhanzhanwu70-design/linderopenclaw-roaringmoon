### 商業模式評估
- Linder 目前把 OpenCode 包成 Docker image 給客戶
- 想轉移到 NemoClaw + K3s 包裝
- **結論：** NemoClaw 原生就是 Docker，商業模式完全吻合

### 技術關鍵點
1. **Landlock 安全機制** — NemoClaw 的核心價值
2. **鎖死本地模型** — 修改 `network_policies` 移除外部 API
3. **GPU 分配** — NemoClaw 不做，靠 Docker `--gpus` 或外部排程
4. **Task 分派** — 由 Coordinator Agent 自己用 `sessions_spawn`/`sessions_send` 做
5. **K3s 包裝** — 官方不支援，但可用 Docker commit 方式

### 客戶交付流程
```
1. 架好 NemoClaw Sandbox
2. 設定 Policy（只有本地模型）
3. shields up 鎖死 config
4. docker commit 成新 image
5. docker save 成 .tar.gz
6. 客戶 docker load + docker run
```
