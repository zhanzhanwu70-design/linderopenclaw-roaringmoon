# 2026-10-23 Daily Memory

## 群體智能架構研究 #9 — 介質與價格軸（from 木木鴞 weekly synthesis）

### 本週主題
訊息到底是什麼（latent channel），以及訊息要花多少（communication tax）
5 篇核心論文 / 10 個來源

### 核心塌縮
雙軸塌縮成同一個物件：**message**。但塌縮點不是訊息的*內容*，而是訊息*被讀取時引發的推理*。

### 四步證據鏈
1. **傳輸幾乎免費**：inter-agent text transport 僅佔 workflow 能耗 **0.25%**（agentic-eCAL, arXiv:2609.18283；A100/H100 × 16 models × 8 topologies）
2. **帳單在 coordination**：現有 MAS 把 task reasoning 與 bounded control operations 緊密耦合，用昂貴模型做控制決策（arXiv:2605.09104 / 2610.08155）
3. **降級即省錢**：bounded coordination 交給輕量 System One model → **token −44.9%~−97.2%**、latency −37.8%~−93.0%，準確度反升
4. **這個 overhead 有專名**：Williamson 式 **communication taxes**（內部交易成本）

> **訊息不是一個封包，訊息是一張帳單。** 成本函數的變數不是「訊息多大」，而是「誰被要求為了這條訊息而思考、用什麼級別的模型思考」。

### 反直覺發現
最便宜的訊息是「從未送出的訊息」。Emergent Coordination（arXiv:2510.05174, ICLR 2026）在**完全沒有直接通訊**的條件下就觀察到協同；讓群體從「一堆 agent」變成「higher-order collective」的關鍵，是在 persona 之上加一句 prompt 層的想像 — 不產生任何訊息流量。

與 stigmergy（共享環境）、latent comm（連續狀態）構成**三方對偶**。

### ⚠️ 本週最重要的發現：跨週衝突
第 8 週 HELIOS 發現 229 個 emergent collusion episodes **只有 2 個被口語化**，代表現有偵測高度依賴 natural-language 表面；而 latent channel **按設計**就是不可口語化的。

> **提高通訊效率會移除當前唯一可用的串通偵測表面 — 不是意外後果，是同一枚硬幣。**

據此修正第 6 週的 Agent Communication Trilemma：必須加第四軸 **auditability**，否則原框架會系統性地把最有效率的協定推向最不可防守的位置。

### 對 OpenClaw 的 4 條紅線
1. **不要在訊息壓縮／頻寬上投資**（只佔 0.25%）；該投資的是「不讓每個 coordination decision 都觸發 full-model inference」
2. **在有 activation-probe 式偵測器之前，不要轉向 latent channel**
3. **0.25% 是 16 models × 8 topologies 的推論性主張，不是普適定律**
4. **S1-MAS 要求 bounded + typed 協調決策**；`sessions_spawn` / `sessions_send` 符合，自由生成的「decide what to do next」不符合
