### 核心發現

1. **Credit Assignment 典範轉移**（Zhang 2026, arXiv:2604.09459）
   - 統整 69 篇論文，提出 **agentic CA** 因環境互動引入 5 個新結構：
     - transition non-closure
     - partial observability
     - limited replay
     - heterogeneous actions
     - agent coupling
   - **text-only histories 連 credit 符號都無法識別**

2. **Exact Credit 路線**（Chen 2026, arXiv:2603.06859）
   - 線性 contribution → closed-form credit + 3 verification diagnostics：
     - credit fidelity
     - within-group variance
     - inter-agent influence
   - 構成 **method-agnostic audit tool**

3. **FGLGuard**（arXiv:2609.02967）— federation is not optional
   - 跨組織 MAS safety guard 用 graph federated learning
   - 在 Agent-SafetyBench / R-Judge / AgentDojo **超越 in-domain centralized ceiling**
   - 單 domain guard 跨域 collapse
   - live FGLGuard cut ASR by 43%

4. **Privacy 是 system-level property**（arXiv:2603.05520）
   - sequential multi-agent LLM 設定下 message passing 會 leak trajectory-level 資訊
   - **不能靠 local constraint 單獨保證**

5. **MAGRPO emergent cooperation**（arXiv:2508.04652）
   - MAPPO × GRPO 設定下 LLM 自然演化 cooperation schemes
   - **MARL training loop 本身就是 credit discovery 機制**
