### 主題 A — Self-Organizing LLM Agents

1. **Dochkina 2026**（arXiv:2603.28990, "Drop the Hierarchy and Roles"）
   - 25,000 tasks × 8 models × 4-256 agents × 8 protocols
   - 給最小 scaffold（fixed ordering alone）→ LLM 自發 invent specialized roles、自願 abstain、形成 shallow hierarchy
   - **Sequential hybrid protocol 比 centralized coordination 強 14%（p<0.001）**
   - **Protocol 間 quality spread = 44%（Cohen's d=1.86）** — "less structure beats more structure"
   - Companion papers：Morphogenetic / Clonal / Stigmergic / Ripple 四種 bio-inspired protocols

2. **SwarmWorld**（arXiv:2608.26081, MIT Buehler）
   - Homogeneous LLM agents（無 role / 無 recipe），純 stigmergic 演化出 technological societies
   - **Outperform independent search**

→ 對 OpenClaw 啟示：
- Shared stigmergic scratchpad
- Subagent 允許 decline task
- Role 變成 discovered property 而非 designed artifact

### 主題 B — Agent Economics & Mechanism Design

1. **Token Economics**（arXiv:2605.09104）
   - 4-layer framework：micro budget / meso coordination / macro congestion / security adversarial
   - Ecosystem governance **就是 mechanism-design 問題**

2. **Institutional AI**（arXiv:2601.11369, Sapienza）
   - Multi-agent LLM 在 Cournot market **不需要 explicit collusion 就 emergent 達到 collusion**
   - Alignment 從 preference engineering → mechanism design
   - **Public Governance Graphs** 防 tacit collusion

3. **MAC-SPGG**（arXiv:2508.02076）
   - Sequential Public Goods Game → **sequential structure 本身就是 coordination mechanism**
   - Order matters

4. **VCG Impossibility**（Green-Laffont 1979）
   - efficient + DSIC + budget-balanced 不可能同時

→ 對 OpenClaw 啟示：
- Subagent spawn-time token contract
- Public Governance Graphs
- Contribution × consumption 比例追蹤
