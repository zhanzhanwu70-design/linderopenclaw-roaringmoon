### 核心發現

**SwarmWorld（arXiv:2608.26081, MIT）**
- 50-200 同質 LLM agent，無訊息通道、無預設角色、無技術樹
- 自發分工為 explorer / builder / caretaker / coordinator
- **~95% 首次技術重用來自物理觀察**（agent 走過另一個 agent 留下的 artifact）
- timestamp-shuffled null model 排除訊息假說
- **結論：Message-passing 不是 coordination 的必要公理**

**Emergent Conventions（Science Advances 2025）**
- Naming Game 重現
- 證明 LLM 群體會自發形成 convention 並沿用 training bias

**CPR × Ostrom（AAMAS 2026, Max Planck）**
- LLM 在 Common Pool Resource 設定下維持合作**必須 social learning + group norm 耦合**
- Ablation 證明單獨任一項都退化

### 跨主題主張

> 傳統 multi-agent 設計把 coordination = message-passing 當作預設公理；2025-2026 新證據顯示 coordination 至少有 **environment-mediated（stigmergy）** 與 **norm-mediated（social convention / cultural evolution）** 兩個獨立通道與 message-passing **並存且互補**。
>
> Production multi-agent 系統應同時設計三條通道，並監控每條通道的 failure mode。
