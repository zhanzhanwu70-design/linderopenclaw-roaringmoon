### 五條核心命題
1. **多 agent 的成本不是協議成本而是分解成本**：OFP 實測 7.2 ms/handoff = 0.11% wall time（2,430 次 handoff）；分解卻 3.22× 成本 / 3.24× 時間 / 準確率不升（class tier C 87.8% vs A 90.2%）
2. **損益平衡可閉式算**：`f★=(α−1)/(α(1−r))`，**硬可行性上限 α<1/r**（r=0.5 → 2.0，α=2.0 時 f★=1.00 無解）；延遲門檻多一個 θ（協議稅沒有便宜模型對應物）
3. **真正的對手是 router 不是單次呼叫**：逐 task oracle 94.3% @ $0.0098/solved vs 零樣本 router 71.4% @ $0.0046；「逐任務路由完全不需要任何 inter-agent protocol」
4. **古典共識三假設在 LLM 上全崩**：λ<0 主動排斥無法被任何非負行隨機矩陣表示（八模型 73,080 次量測：A1 逃逸 22.3–68.3%、λ<0 4.7–24.2%、真實族群直徑在 5.9–25.6% 的回合變大）；**λ₂ 與平均度解釋最終族群均值變異 0%**；framing 才是高槓桿變數（位移最高 0.851）；頑固少數只讓族群碎裂（3B 共識率 90.7%→16.7%）
