### 主題 A — 群體決策（Group Decision-Making）

1. **Debate or Vote（NeurIPS 2025 Spotlight）最有衝擊的結論**
   - 把 MAD 拆解後，**majority voting 單獨就佔了絕大部分 gain**
   - 辯論本身理論上 induces a martingale over belief trajectories → 不提升 expected correctness
   - 實務意義：5-15x token 成本的 debate pipeline 多數時候不划算，預設用 vote / ensembling

2. **EMS**（arXiv:2604.02863）：priority agent 先 vote + early stopping，省 token 不犧牲 accuracy

3. **Representative Social Choice × AI Alignment**
   - Cambridge + Berkeley Russell 同聲主張 social choice 取代 RLHF 的 single scalar reward

4. **Emergent Social Conventions**（Science Advances）
   - LLM groups 自發形成 conventions + group polarization
   - 需要 explicit convention audit

5. **InfoDelphi**（arXiv:2607.01661）
   - rationale sharing + public/private split + rationale-space aggregation
   - DeepSeek-V3.2 + Llama-4-Scout-17B 都驗證有效

### 主題 B — 分散式 AI 推論（Distributed AI Inference）

1. **Parallax**（arXiv:2509.26182, HKU）：heterogeneous GPU pool + 兩階段 scheduler，真實志願者節點驗證有效
2. **P2P Prefix-Cache Routing**（arXiv:2606.17059）：local radix tree + anti-entropy metadata sync → **weak consistency is sufficient**
3. **Mesh LLM**（2026-07-11 launch）：open-source、iroh QUIC P2P、OpenAI-compatible API、無控制平面，已 production-ready
4. **PolyLink + TIQE**（arXiv:2510.02395）：blockchain edge AI + cryptographic quorum verification 保 inference integrity
5. **FedAgent**（ICLR 2026）：federated agent RL，heterogeneity 仍是 open challenge
