### 核心發現（12 條）

**A. Cross-Org Federation**
1. 真正 gap 不是 authentication，是 multi-hop delegation 後的 authority 邊界
2. Trust 必須 cryptographic，區塊鏈非必要；signed credentials + short-lived tokens + shared reading standards 才是
3. 5-dim trust taxonomy 取代單一 trustworthiness（Zhu et al. 2026-08）
4. Trust Evidence Envelope = immutable workflow manifest + append-only attestations（TaaS, China Mobile Jiutian, 2026-09）
5. IETF WIMSE 是 delegation gap 標準化前線；A2A v1.0 已採用
6. Deployment 落後 spec — ~12% 公開 MCP server 無認證

**B. Multi-Agent Metacognition**
7. MSV 是第一個 ensemble-scale metacog framework（Courchaine/Sethi, WWW Companion 2026）
8. **Knowing-Doing Gap 系統性存在**（Mirror）— LLM 在 wager 模式 calibration 比 natural 模式更好；知道但不穩定地用
9. Proactive Handoff 是 LCNC 風格實證 pattern（Xu/Lu, 2026）
10. MetaCogAgent（前置）+ MSV（runtime）+ Proactive Handoff（trigger）形成完整 timeline
11. **Self-reported uncertainty 是 design anti-pattern** — trust LLM 自己報的 confidence → insufficient
12. Metacog computational cost 是 deployment 邊界；必須 lazy / triggered

---

### 三大啟發（對 OpenClaw）

1. **Subagent 必裝三層 metacog stack**：前置檢查（MetaCogAgent）+ runtime monitor（MSV）+ trigger-based handoff（Proactive Handoff）；全部 lazy / triggered 避免 overhead
2. **Trust boundary 雙軸**：對外走 Identity Mesh lite（SPIFFE-style local ID + signed agent card + WIMSE-style token exchange prototype）；對內走 MSV-driven verification
3. **Reputation system 必須重新設計**：trust score 不能 self-report 聚合（直接衝擊 09-03 結論），必須有 mirror-style external probe baseline

---

### Mirrored Incompleteness Principle（原創）
> 純 cryptographic trust incomplete（能驗 signature，驗不出 self-deception 與 sycophancy）；純 metacognitive trust 也 incomplete（能 internal monitoring，扛不住 cross-org adversarial）。兩者合在一起才是 self-aware trust boundary。
