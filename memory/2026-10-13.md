### 本週主題
Group Decision-Making in LLM-based Multi-Agent Systems — 補完 CDM 的 5 個核心問題
1. 現狀盤點（GEDI）
2. 機制實證（Debate or Vote）
3. 機制選擇條件（Voting or Consensus）
4. 反證（Deliberative Collaboration）
5. 過程品質量測（ICML 2026 Diagnostic Study）

### 5 大核心發現

**1. GEDI（Zhao et al., ICML 2024 workshop）— 現狀揭露**
- 52 個 LLM-MAS 框架盤點
- **~90% 用 dictatorial 或 plurality voting**
- 8 種 ordinal voting rule module（Plurality / Borda / IRV / Minimax / Ranked Pairs / Bucklin / Range / Dictatorial）
- **3 隻 agent 就足以產生 voting synergy**，4 隻有 redundancy
- **Borda Count 對 unreliable agent 最 robust**

**2. "Debate or Vote"（UW-Madison, 2025-08）— 震撼結論**
- 實證 + 數學證明：**MAD 好處主要來自 Majority Voting**
- **debate 本身是 martingale**（E[b_{t+1}|b_t] = b_t）
- 對 OpenClaw 影響：sequential agent 討論可能浪費 token，**parallel sampling + voting** 才是 ROI 較高的設計

**3. "Voting or Consensus?"（Kaesberg et al., ACL 2025 Findings）**
- Voting 在 accuracy 上贏 Consensus
- Consensus 在不可逆 action 必要
- **Consensus 易 anchor 到第一個發言者**

**4. "Deliberative Collaboration"（Wang et al., 2026-07）— 反證**
- Partial observability 下 deliberation 確實提供 reflection + error correction
- → Debate or Vote 結論只適用於 fully observable 設定

**5. ICML 2026 Diagnostic Study**
- 6 個 deliberation 過程 metric：engagement / responsiveness / influence asymmetry / balance / stability / agent utility
- 可做成 deliberation quality dashboard
