## 重要新功能摘要

### 1. Native Ollama Provider 支援 (`be8112f`)
- 透過 `OLLAMA_HOST` 環境變數直接支援本地 Ollama
- 最高優先級 provider 檢測（早於 OPENAI_BASE_URL）
- 無需 API key（使用 placeholder token）
- 模型名稱如 `qwen3:8b` 可繞過嚴格 provider/model 語法驗證

**架構關鍵點**：
```rust
// openai_compat.rs 新增
pub const OLLAMA_CONFIG: OpenAiCompatConfig = OpenAiCompatConfig {
    provider_name: "Ollama",
    api_key_env: "OLLAMA_HOST",
    base_url_env: "OLLAMA_HOST",
    default_base_url: "http://127.0.0.1:11434/v1",
    max_request_body_bytes: 104_857_600,
};

pub fn from_ollama_env() -> Option<Self> { ... }
```

### 2. Setup Wizard 入口點 (`3845040`)
- 新增 `/setup` slash command

- 新增 `RuntimeProviderConfig` struct（kind, apiKey, baseUrl, model）

### 3. 路徑驗證安全改進 (`eb21179`)

- 防止 `>file.txt` 或 `2>&1` 等 redirection 被誤認為路徑
- 正則：`^(?:\d*)?(?:<>|>>?|<)(.+)$|^&>>?(.+)$`

### 4. 命令查詢正規化 (`5babda1`)

## 架構理解

### 雙語言架構
- **Rust**: 核心 CLI、commands、runtime、API client
- **Python**: 輔助工具、porting workspace infrastructure

### Commands 模組 (Rust)
- `SlashCommandSpec` 靜態定義所有 slash commands
- `SlashCommand` enum 完整列舉所有命令變體
- 統一解析入口 `SlashCommand::parse(input: &str)`
- 每個命令有 `resume_supported` 標記

### Provider 路由
```
detect_provider_kind()
  → OLLAMA_HOST (最高優先)
  → ANTHROPIC_API_KEY
  → OPENAI_API_KEY / OPENAI_BASE_URL
  → 其他 provider...
```

### Config 層級
```
RuntimeConfig (Rust)
  → RuntimeFeatureConfig
    → RuntimeProviderConfig (新增)
      - kind: Option<String>
      - api_key: Option<String>
      - base_url: Option<String>
      - model: Option<String>
```

4. **JSON contract 穩定化**：有利於程式化整合
