### 5 大核心發現

1. **A2A 進入 v1.0 時代**
   - 2026-03 v1.0.0、2026-05 v1.0.1，Linux Foundation 治理
   - 5 個核心物件（Task/Message/Part/Artifact/Agent Card）、8 個 Task 生命週期、3 種 transport（JSON-RPC/gRPC/HTTP+REST）、11 個 JSON-RPC method
   - 150+ 組織採用，ACP 2026 中正式 merge roadmap 進 A2A

2. **MCP 2026-07-28 大改版**
   - 走 stateless core，可水平擴展
   - 推 MCP Server Cards + 官方 Registry，朝「npm for agents」演化

3. **主流 Multi-agent framework 對比**
   - LangGraph 仍是 production 部署最大宗
   - OpenAI Swarm 已正式 deprecated（2025-03 由 Agents SDK 取代）
   - Handoff 的結構化 JSON 是跨框架互通的關鍵介面

4. **群體智能在 LLM 上**
   - arXiv 2506.14496 實證：Boids 可在 LLM 重現，但 ACO 的 pheromone 機制難直接移植（需 vector store 模擬 stigmergy）
   - 根本差異：通訊成本、個體一致性、可觀測性、可重現性都跟真實 SI 不同

5. **光譜觀察**
   - 標準化互通（A2A/MCP）vs 去中心化湧現（Boids/ACO）不是對立而是 spectrum
   - 高風險任務偏左（標準化）、高探索任務偏右（湧現）
