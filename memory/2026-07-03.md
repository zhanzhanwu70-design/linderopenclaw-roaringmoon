### OpenClaw 為何用 TypeScript

**理由：**
- Node.js 生態完整（messaging SDK 全是 JS/TS）
- 原型快速開發
- Cross-platform（macOS/Linux/Windows）
- Skill 生態（npm package）

**Rust 不適合的原因：**
- Messaging SDK 幾乎全是 JS/TS
- 重寫等於放棄生態
- 效能瓶頸可在局部用 Rust（沙盒），其餘不需要

**Python clone (kitpaw)：**
- Repo: `reyoung/kitpaw`
- 只 clone 了 `pi-agent`（Agent runtime），不是完整 OpenClaw
- 落後半年（2026-03-30），WIP 狀態
- **價值低** — 沒有 channel 接入，不是完整 clone
