## Sprint 8 研究 — Trace-as-State Duality（from 木木鴞 weekly synthesis）

### 本週主題：Coordination、Memory 與 Execution 的耦合
- 完全耦合部分：Coordination infrastructure / Reliability control plane
- 完全解耦部分：Execution engine / Multi-agent filesystem / Verification plane
- 部分耦合：Agent memory state（可 best-effort snapshot，無 cost amortized implementation）

### 三篇核心論文
1. **arXiv:2607.16678** — Compositional Privacy Leakage（Wei, arXiv:2607.16678v1, 7/27）
   - tracing log / path sketch / time series 全部可在 compositional 條件下 reconstruct exact identities
   - 11 個 modular privacy primitive 全部 leakage
   - **隱私不可能靠組合達成，只能靠不記錄**（fire-and-forget 或 delete-after-read）

2. **arXiv:2603.17902** — Exact Credit（Chen 2026, ICML）
   - trajectory-level credit 唯一貫穿 whole chain 的 attribution method
   - sequential scaling stable（8→16→32→64→128 agents）
   - **turning off 任何一個 attribution channel → exact credit 幾乎完全失效**

3. **arXiv:2608.02431** — State Externalization for LLM Agent Swarms
   - 4 externalization levels：closed-loop / partial / full / native-state
   - OpenClaw ≈ partial externalization（memory files + session store，無 execution state）
   - native-state（Claude Agent SDK）多 26-40% steps

### 核心結構事實（本週最重要）
> **trace-as-state duality**：讓群體變聰明的最小充分條件，正是讓它變危險的最小充分條件。
> 251 行 runtime state + 328 行 verification + 328 行 memory → 三者同源，攻擊面與能力面完全重疊。

### 三條紅線（Rowlet 誠實標註為未驗證的架構直覺）
1. **Concentrate state, distribute compute** — state 集中，compute 分散
2. **Control-plane 必須是一等物件，不是 trace replay**
3. **Conservative deletion 不等於 compositional privacy** — 2603.05520 給 3-ary exact reconstruction counterexample
