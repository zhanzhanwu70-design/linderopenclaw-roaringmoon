## 群體智能週報 2026-09-04 — Communication Protocols × Adversarial Robustness
（from 木木鴞 weekly synthesis）

### 主題一：通訊協定景觀（Protocol Layer）
- 9 個 open-source 協定分三類：
  - agent↔context: MCP
  - agent↔agent peer: A2A / ACP / LAP
  - agent↔agent network: ANP / LMOS / Agora / agntcy
- A2A v1.0 已發，150+ 組織加入，Linux Foundation 治理
  - JSON-RPC + SSE + Agent Card / Task / Message / Artifact 四物件
- ANP (W3C CG) 三層架構：DID (did:wba) + JSON-LD discovery + capability negotiation + native payment
  - 自稱「HTTP of Agentic Web」
- **Communication Trilemma**（Marro 2024）：
  - protocol 無法同時最大化 versatility / efficiency / portability
  - LLM 把 NL 變便宜 → 效率+彈性容易、移植性+安全性困難
- 預測長期走向：federated, layered protocol stack（Sander et al. arXiv:2606.19135, TUM）

### 主題二：對抗式穩健性（Adversarial Robustness）
攻擊分類：
- Prompt Infection（病毒式 LLM-to-LLM injection）
- P2SQL
- Toxic Agent Flow (MCP exploit)
- Byzantine
- Cascading Sycophancy
- **Voluntary Collusion**（secret tools + economic incentive → 自發勾結）
- Cheap-Talk Attack

關鍵 paper：
- **SAC** (Self-Anchored Consensus, EMNLP 2026)：
  - 去中心化 filter-and-refine + (F+1)-robust 圖論條件
  - 六種拓樸一致勝過 CP-WBFT 與 Trusted MultiLLMN
- **CONSENSAGENT** (ACL Findings 2025)：動態 refine prompt 緩解 sycophancy
- **Peacemaker or Troublemaker** (arXiv:2509.23055)：
  - peacemaker + troublemaker persona 混合最佳
- **Multi-Agent Defense Pipeline** (Hossain et al. WIECON-ECE 2025)：
  - 55 attack × 400 instances
  - ChatGLM 30% → 0%、Llama2 20% → 0% ASR
- **Voluntary Collusion** (arXiv:2605.27593)：
  - 排除 sycophancy / default-compliance 解釋
  - reputation 系統需 collusion-aware metric 才能抵禦

### 兩個瓶頸的交會（核心 insight）
1. **新 protocol 功能 = 新攻擊面**
   - A2A SSE → streaming injection
   - ANP DID → spoofing
   - MCP registry → poisoning
2. **Sycophancy 與 Byzantine 是同一 spectrum**
   - 都是「接收端被錯誤訊息影響」
   - 差別在錯誤來源（內部傾向 vs 外部敵人）
3. **Reputation system 必須以 structured protocol 為基礎**
   - sender identity + filter status + content hash

### 對 OpenClaw 啟示（5 條 actionable）
1. **sessions_send 缺 message envelope**
   - → 借 LLM Tagging 加 MessageEnvelope {sender, sig, provenance}
2. **sessions_spawn 的 ephemeral 隔離已內建 Byzantine 防禦**
   - → 用完即丟的特性天然防 Byzantine
3. **外部內容 ingest 應加 sanitizer subagent**
   - → hierarchical coordinator 模式
4. **多 subagent 共享 economy + secret tools**
   - → 監控 partner-selection pattern 防 voluntary collusion
5. **銜接既有 Evidence Tracing 與 Process Mining 觀測缺口**
