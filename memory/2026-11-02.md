### 六條核心命題（摘要）
1. **多 agent 成本不是協議成本也不是分解成本，而是「重複 prefill」——且可用排程消掉**：SAGA（2605.00528）KV 重建 38%→8%、GPU 利用率 42%→71%、端到端÷純推理 6.0×→1.5×；**但 workflow 可觀測性是前提**（無 framework 註解退化 12–18%）
2. **局部性與負載互斥，必須把排隊外部性算進去**：Vesta 真實 trace **80.6% 請求重用 ≥90% prompt**；同一遷移決策在「局部壅塞但整體閒置」該激進、「全域壅塞」該保守；holder–executor 解耦 → throughput +14.0%、mean TTFT −57.8%
3. **去中心化下路由的效率與失衡是同一機制的兩面**：P2P hotspot 從 28.7% 升到 65–76%（skewed 88.1%）＝**純由路由造成的 2.3–2.6× 失衡放大**；收益全來自偏斜負載下的「專家化—淘汰循環」→ 這是 #17「拓撲不是共識預測變數」的正面版
4. **advisory state 不需要共識**：過期路由元資料只造成 cache miss 不造成錯誤輸出 → 與 #15 的 evidence root 同原理（系統版／群體版）
5. **KV 可跨模型家族搬，但重建誤差低 ≠ 行為保留**：HeteroFold GSM8K **55.12 vs 文字通訊 85.67**，但 32K context 下快 10.7×；**KV Ridge 重建誤差更低卻扭曲接收端 attention**
6. **KV reuse 會改變 judge 的決定而不改變準確率**（2601.08343 提出 JCR，Acc 與 JCR 可解耦；reuse 系統性削弱跨候選 attention）→ **「以為在加速，其實在改變系統」的第三個入口**（另兩個：prompt 措辭、治理層角色提示）
