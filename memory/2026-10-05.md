### 三個關鍵來源

**arXiv:2607.13104** — *Self-Improvements in Modern Agentic Systems: A Survey*（Schmidhuber 合著, 97 pages）
- 雙軌分類：
  - **Foundation Model improvement** (77 篇) — 修改 LLM 本身
  - **Scaffolding improvement** (176 篇) — 修改 orchestration / memory / prompts / tools
- OpenClaw 100% 落在 **scaffolding branch**

**arXiv:2607.05297** — *MetaSkill-Evolve*（Wang et al.）
- **Two-Timescale 設計**：
  - Fast loop：改 task skill
  - Slow loop：用同一個 pipeline 改 meta-skill 自己
- 量化結果：
  - OfficeQA: +23.54 pts
  - SealQA: +16.09 pts
  - ALFWorld: +1.92 pts

**arXiv:2607.12254** — *SARSI*（Yang, v2）
- 最完整的 RSI safety 設計：
  - Functional self-awareness
  - Goal contract
  - Bounded scope
  - Validated tool registry
  - End-to-end benchmarks
  - Owner-controlled autonomy
