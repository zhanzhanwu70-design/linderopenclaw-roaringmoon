## Paper Deep Dive — Multi-Agent Authority Benchmark
（from 木木鴞 paper ingestion）

### Paper 識別
- **arXiv:** 2607.15434
- **Title:** Multi-Agent Authority Benchmark: Measuring Conversational Authority in LLM-Based Groups
- **Methodology:** 296 episodes × 32 LLM-based roles × 14 group sizes × 3 reasoning conditions
- **Reproducibility Suite:** released

### 核心發現

1. **Naming-as-Authority Primitive**
   - 當一個 agent 被賦予「名字」（e.g., "Senior Engineer"）會在對話中自然展現更高發言權
   - 不是透過指令 / 系統 prompt，而是**被命名**就足以讓該 agent 在對話中「說了算」

2. **Group Size 非線性效果**
   - 從 1 → N 個 agent，authority distribution 不是線性衰減
   - 有 threshold，超過之後出現「權威固化」(authority lock-in)

3. **Reasoning Condition Effect**
   - 啟用 reasoning (CoT / latient reasoning) 會改變 authority perception
   - 不同 reasoning 模式對命名權威的接收度不同

4. **Authority 是 emergent property**
   - 不是 protocol 強加，是 group dynamics 自然產生
   - 與 09-09 Dochkina 的 "self-organizing agents" 一致
